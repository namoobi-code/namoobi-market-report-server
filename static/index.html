자동매매 — 선정 종목 집행 (KIS Open API)

TradingAgents(④)가 고른 종목을 namoobi-kis-autotrade 가 한국투자증권 Open API 로 집행한다. 여기서부터는 실제 자금이 움직인다 — 스크리닝(④)까지는 틀려도 손해가 없지만, 이 단계는 버그 하나가 곧 손실이다. 안전장치를 먼저 만들고 로직은 그 다음이다.

진행 순서 — 되돌릴 수 없는 단계는 마지막에

필수 안전장치 (이것 없이는 실계좌 금지) — ① 킬 스위치: 파일/플래그 하나로 전 주문 즉시 중단 ② 일일 손실 한도: 도달 시 당일 매매 정지 ③ 1회·1종목 주문 한도: 오류가 나도 피해가 한정되게 ④ 중복 주문 방지: 재시작·네트워크 재시도 시 같은 주문이 두 번 나가지 않게 (멱등키) ⑤ 전 주문 감사 로그: 무엇을 왜 샀는지 사후 추적 가능하게 ⑥ 장 시작 직후·마감 직전 회피: 변동성 급등 구간
⚠️ API 키·계좌번호는 저장소에 커밋하지 않는다 (SECURITY/ 분리 · .gitignore). ⚠️ 이 대시보드는 주문을 내지 않는다 — 집행은 별도 프로세스에서만.

④ 코스닥 신용 — 마진콜 조기경보

설계 근거: 마진콜 반대매매는 신용잔고율이 높은 코스닥 중소형주에서 먼저 터지므로, 코스닥 신용잔고의 상대적 급감이 조기 신호. 상단 = 코스닥 신용잔고 vs 코스닥 지수 vs 전체 중 코스닥 비중, 하단 = 잔고 일간 증감(감소=적색) — 자발적 상환+강제청산 합산의 근사치.
